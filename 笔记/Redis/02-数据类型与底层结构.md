# 2. 数据类型与底层结构

| 类型 | 底层编码(Redis 7.0+) | 说明 |
|------|--------------------|------|
| **String** | SDS(简单动态字符串) | 空间预分配、二进制安全、O(1) 取长度 |
| **Hash** | listpack / hashtable | 元素少且小用 listpack,否则 hashtable |
| **List** | quicklist(节点为 listpack) | 兼顾内存与随机访问 |
| **Set** | intset / listpack / hashtable | 全整数用 intset,少量小元素用 listpack |
| **Sorted Set** | listpack / skiplist + dict | skiplist 支持范围查询,dict 支持 O(1) 取分值 |

> **注意**:Redis 7.0+ 用 **listpack** 替代了旧的 **ziplist**,因为 ziplist 有"连锁更新"问题(连续 entry 都接近 253 字节时,一个变更触发全连锁扩容)。

## SDS 相比 C 字符串的优势
- O(1) 获取长度(C 字符串要遍历到 `\0`)
- 二进制安全(不依赖 `\0` 判断结束,可存图片/序列化数据)
- 空间预分配 + 惰性释放,减少内存重分配次数
- 兼容部分 C 字符串函数

## Sorted Set 为什么用跳表不用红黑树
- 范围查询(ZRANGE / ZRANGEBYSCORE)实现更简单
- 实现复杂度更低,内存可控
- 并发友好(理论上可做局部锁)
- 配合 dict 实现 O(1) 取分值,各司其职
