# 5. 缓存常见问题

## 穿透(查不存在数据)
- 现象:查询根本不存在的数据,绕过缓存直击 DB(常被恶意攻击)
- 解决:
  - **布隆过滤器**:请求前先过滤,空间高效
  - **缓存空对象**:查不到也缓存 `null`,设短 TTL

## 击穿(热点 Key 过期)
- 现象:热点 Key 过期瞬间,高并发直击 DB
- 解决:
  - **互斥锁**:只让一个线程查 DB 并回填缓存,其他等待
  - **逻辑过期**:热点数据永不过期(不设 TTL),value 中存逻辑过期时间,后台异步更新

## 雪崩(大量 Key 同时过期)
- 现象:大量 Key 同一时刻过期,DB 瞬间压力暴增
- 解决:
  - **过期时间加随机值**,打散过期时间
  - **多级缓存**(本地 + Redis)
  - 熔断降级保护 DB

## 缓存与数据库一致性
- **首选旁路缓存(Cache Aside)**:**更新数据库 → 删除缓存**
  - 为什么删除而不是更新?避免并发更新导致缓存与 DB 不一致
- **延迟双删**:先删缓存 → 更新 DB → 休眠毫秒级 → 再删一次
  - 解决"读线程把旧值回填缓存"的并发问题
- **消息队列异步重试**:删除失败时发 MQ 重试,保证最终一致性
- **Canal 订阅 binlog**:监听 DB 变更异步刷缓存,业务代码无侵入
