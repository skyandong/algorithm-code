# 常见攻击与防御

> **核心认知：所有攻击都在回答同一个问题——"协商过程中哪一步可以骗过谁"。
> 理解三类攻击面就够了：
> 砍参数（降级：逼你用弱算法）、
> 看侧门（侧信道：从密文长度、时间等旁信息偷东西）、
> 钻实现漏洞（协议没错，代码写错）。
> TLS 1.3 的设计哲学：与其打补丁，不如直接砍功能。**

---

## 第一类：砍参数（降级攻击）

**套路**：中间人篡改 ClientHello，把客户端支持的版本和强算法删掉，骗双方用弱配置。

```
客户端发出: "我支持 TLS 1.3 + 一堆强算法"
中间人改成: "我只支持 TLS 1.0 + 弱算法"
服务器一看，那就用弱的吧 → 双方都以为在对称协商，其实被压了级
```

**防御（1.3）**：ServerHello.random 埋降级暗号 `DOWNGRD`。服务器真支持 1.3 却被迫谈 1.2 时会埋暗号，客户端看到立即断连。配合 Finished 的抄本哈希——中间人改了 ClientHello，哈希就对不上，双重保险。

## 第二类：看侧门（侧信道攻击）

不正面破解密码，从"旁边的信息"偷东西。共同套路：**压缩/长度作为信息泄露通道**。

### CRIME（2012）/ BREACH（2013）：压缩泄密

```
前提：攻击者能让请求里带上猜测的前缀（如注入脚本触发
     "GET /?q=Cookie:session=X"），且响应/请求被压缩

原理：猜对了 secret 的一个字符 → 压缩算法找到重复 → 密文变短一点
      猜错了 → 没有重复 → 密文长一点
      长度本身就是信息 → 逐字符试出整个 session cookie
```

- CRIME 打 TLS 层压缩 → TLS 1.3 直接禁了压缩
- BREACH 打 HTTP 层 gzip → **今天依然有效**，防御靠应用层：CSRF token 随机化、secret 与攻击者可控内容隔离、响应加随机 padding

### BEAST / POODLE：CBC 模式之殇

都是利用 CBC 加密模式的缺陷（IV 可预测 / padding 不校验）。防御= 弃用旧版本 + 全面转向 AEAD。

## 第三类：钻实现漏洞

**Heartbleed（2014，震动业界）**——协议没错，OpenSSL 写错了：

```
攻击者: Heartbeat 请求 "我发了 1 字节数据，请回显"（实际 payload 长度字段写 65535）
OpenSSL: 不检查实际长度，直接回读 65535 字节内存 → 私钥、session 全泄露
```

教训：**数学上无懈可击的协议，会被一个不检查长度的 C 程序员毁掉。**

## 中间人（MITM）：体系级对抗

攻击者伪造证书冒充服务器。防御靠整个 PKI 体系：证书链验证 + Certificate Transparency（CT 日志监测未授权签发）+ CAA DNS 记录（限定哪些 CA 能给域名签证书）。

## 攻击速查表

| 攻击 | 类型 | 打哪 | 一句话原理 | 防御 |
|------|------|------|-----------|------|
| 降级 | 协议 | 协商 | 篡改版本/算法清单 | 1.3 降级暗号+抄本哈希 |
| MITM | 体系 | 证书 | 伪造身份 | PKI + CT |
| BEAST | 密码学 | TLS 1.0 CBC | IV 可预测 | 升级版本/AEAD |
| CRIME | 密码学 | TLS 压缩 | 压缩长度泄密 | 1.3 禁压缩 |
| BREACH | 应用 | HTTP gzip | 同上 | token 随机化等应用层手段 |
| POODLE | 密码学 | SSL 3.0 | padding 不校验 | 弃用 SSL 3.0 |
| Heartbleed | 实现 | OpenSSL | 不检查长度 | 升级库（协议无辜） |
| 重放 | 协议 | 0-RTT | 原样重发早期数据 | 只承载幂等请求 |

**注意最后一行**：0-RTT 重放不是历史故事，是 1.3 普及后**当下就要防**的问题。

---

## 为什么 1.3 的答案是"砍"

| 被砍功能 | 喂饱了哪个攻击 |
|---------|---------------|
| RSA 密钥交换 | 私钥泄露→历史全解（无前向安全） |
| 压缩 | CRIME |
| 重协商 | 重协商前缀注入 |
| 静态 DH | 无前向安全 |
| CBC（仅剩 AEAD） | BEAST/POODLE/Lucky13 一窝 |

设计哲学：**可配置的安全=可错配的安全**。少一个选项，少一个坑。
