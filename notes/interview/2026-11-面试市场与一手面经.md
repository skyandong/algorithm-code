## 1. 结论（只读这节也够）

**市场是「总量冷 + 结构剧变 + 冷热分层」，不是笼统的寒冬。**

| 判断 | 依据 |
|---|---|
| 卡点在简历关，不在技术关 | 真实社招样本：boss 投递 2700+ → 换简历 700+ → 一面 70 场（**2.59%**）；但一面进二面 40%、二面进三面 39%、三面进 HR 82% —— 一旦进面，通过率正常 |
| 纯 Go 岗缩，AI/Agent 岗放量 | BOSS 北京 golang 首屏 15 条里，标题带 AI/Agent 的过半；但真正的 5-10 年档很少 |
| 你这一档在猎聘，不在 BOSS | 5-10 年岗占比：猎聘 **43%** vs BOSS 首屏 **27%** |
| 薪资没崩，压的是性价比 | 北京 5-10 年 Go 岗 25-50k 为主，高位 40-75k；1-3 年 15-25k |

**你的定位**：6 年 + 外包 + 有 Agent 落地经验。障碍是**筛选环节的出身标签**，不是能力短板——所以策略是换渠道、换叙事，不是继续刷题。

**冷热分层**：

- 纯 Go 业务迭代、简历无量化成果 → 寒冬
- 能讲清架构取舍、有高并发量化 → 中性偏冷
- **有 Agent/RAG/大模型落地 → 局部暖春**（岗位多、给价高、不少「学历不限」）

## 3. 面试怎么考

### 3.1 三条完全不同的链路

| 环节 | 互联网大厂（社招） | 华为 | 银行 / 金融科技（如兴业数金） |
|---|---|---|---|
| 独立笔试 | **通常没有** | 机考（部分岗位，约 2h） | **有** |
| AI 面试 | 少见 | — | **有**（笔试后） |
| 技术面 | 2-3 轮 × 约 60 min | 技术一面 + 二面 | 真人面 |
| 收尾 | HR 面（谈薪定级，不是走过场） | 主管面（纯行为面 40 min） | 视情况 |
| 周期 | 1-3 周 | 线下一天连轴 | 最长 |

### 3.2 笔试：社招基本没有

`赛文X` 那个 2700 次投递的漏斗里，阶段是「投递 → 换简历 → 一面 → 二面 → 三面 → HR」，**没有笔试这一环**。笔试集中在：华为式统一机考、银行/金融科技、部分中厂国企。校招才是笔试主战场（ACM 模式 3-5 题）。

### 3.3 手撕：少得离谱

一位候选人复习 300 题（精刷 100 题），**面了 10-20 场，实际只做了 3 道题**（小红书「社招还用刷力扣嘛」评论区，2026-10）。评论共识：「别刷了，把心思放到产品和业务上」「面试官自己也不想考」。

出现的题都很轻：连续子序列最大和、滑动窗口最长不重复子串、股票、背包、LRU、链表两两交换。

### 3.4 AI 面试已经进流程

银行系社招的 AI 面，评论原话：「八股为主，**会从一个问题入手一直深挖**」「按项目内容提问」「天马行空，但你可以引导它」。

应对：AI 面不爱听铺陈，它顺着简历词条问，答得含糊会被一直追；主动用「我这边主要做的是 X」把话题拉回你真做过的领域。

### 3.5 节奏：快得没法并行

- 京东：原话「推进很快，基本过几分钟就会约下一轮」
- B站：一面→二面隔一周，二面→三面隔三天，HR 面后三天发意向书
- 华为：线下一天走完三轮，平均 53 分钟/轮
- 共性：一面过了当天就约下一场 → **多家并行几乎不可能**，要按期望从高到低分批投

## 4. 真题（一手源）

### 4.1 B站 P6 三轮（5 年 Go，B 级 · 面经作坊号，只取题目形态）

> 来源：小红书 @程序员明哥（该号简介卖「邪修面试辅导 + 大厂内推」，判定 B，见 7.2），2026-11-02。

- **一面（60 min，一线工程师）**：GMP 不问定义，问「goroutine 执行超 10ms 调度器怎么抢」；GC 三色标记 + 写屏障，追问「混合写屏障解决了什么」；sync.Map 的 LoadOrStore 是不是原子读写组合；channel 关闭带缓冲后 range 行为；slice 共享坑；pprof 追问「看 top 还是 trace、block profile 何时用」；项目追问「消息重试阶梯怎么定，为什么不是固定间隔」；**没写算法，但考了 SQL 窗口函数**（row_number/rank/dense_rank + 「近一周每天播放量前 10」）
- **二面（60 min，组长）**：「你怎么设计索引，不是优化，是从零设计」；复合索引给具体 SQL 判走不走；SQL 慢排查「explain 什么情况下不准」；zset 底层；红锁「什么情况下会失效」；TCP 可靠为什么还丢包、**大量 CLOSE_WAIT 什么场景**；流量翻几倍怎么处理（限流放哪层、降级降什么、热点怎么扛）；手撕连续子序列最大和
- **三面（40-50 min，总监）**：最难的技术决策（选项/为什么/后不后悔）；给某业务做微服务拆分并治理；Kratos vs gin 解决什么层面；「从头搭」而非「修现成系统」

## 5. AI 考点：要补什么

**答题骨架（C 级来源，只取框架）**：

- **模型输出不可靠的三层防线**：① 格式校验（JSON Schema / 字段存在性 / 枚举）② 事实校验（规则引擎、可信数据源、轻量模型交叉验证）③ 安全合规（输入侧权限过滤 + 输出侧审核网关）
- **Agent 调用失败的兜底四层**：调用层（熔断、超时、指数退避 + jitter）/ 推理层（打 trace、降级为纯模型回复、窗口截断）/ 模型层（幻觉、格式、违规）/ 消费层（防御式解析、默认值、降级到静态策略）；收尾一句「兜底链路要用混沌用例验证真能走通」
- **AI coding 被考的是**：任务拆解、上下文裁剪、权限判断、审查验证、解释取舍；**「一把梭不 review」是明确减分项**

**但真题比框架更深**：父子 agent 通信、记忆管理、意图识别、95% 准确率如何用评测集验证、KV Cache 能不能进 Redis、SSE 断连重连、rerank 放哪层。这些只能靠你真做过。

## 6. 你的策略（外包 + Agent 怎么打）

### 6.1 外包的三个真实摩擦点

1. **简历筛**：HR/用人方按公司类型过滤，这是 2.59% 漏斗里最大的一道坎。
2. **薪资基准**：外包包偏低，下一家会拿它当锚点。
3. **叙事默认值**：面试官默认「外包只做执行，不做决策」，你得主动打破。

### 6.2 简历改写

- **项目在前，公司名在后**：写成「某教育科技公司 · AI 应用方向（合作形式派驻）」，诚实但不让「外包公司名」抢走第一眼。
- **每条按「背景-方案-难点-结果」写，带数字**。外包经历最常被质疑「不知道你在里面做了什么」——你负责哪块、做了什么决策、什么量级。
- 手上有实测素材就写实测：比如 OCR 候选方案的延迟对比（约 11s vs 6s、超预算）、坐标归一化的下游适配问题——这类「我测过、我判断过」的细节最能翻盘。

### 6.3 渠道与目标

1. **内推 > 官网 > BOSS**。外包背景在 BOSS 上最容易被按公司类型筛掉；内推能直接到用人方。
2. **主战场是猎聘 + 猎头**（5-10 年占 43%），不是 BOSS（27%）。
3. **优先投 AI/机器人方向**：给价高（30-60k）、常写「学历不限」、认 Agent 经验，且接受 3-5 年。
4. **明确划掉**：外派/驻场 15-20k、短期 1-3 个月、「学信网可查」类流水线岗。

### 6.4 6 年投 3-5 年岗怎么说

可以投，但必须主动管理「overqualified」标签：

- **BOSS 上期望薪资调到目标岗下沿**，别写现包——这一栏直接决定能否进初筛
- **开场就给业务理由**：「我看 AI Agent 方向，这个岗虽然写 3-5 年，但做的事和我 6 年的分布式/高并发对得上」
- **判断弹性岗**：JD 同时出现「3-5 年」+「独立负责 / 从 0 到 1」→ 弹性；只写年限 + 罗列技术栈 → 真卡年限
- **别海投**：每次都要解释「为什么降级」，很耗轮次。挑 5-8 家真正想去的

| B站 | `x/web-interface/view` 与 `x/v2/reply` 可 curl 免登录取元数据/评论 | `view` 与 `player/v2` 的 subtitle tracks 全空，转写只能靠 ASR 或 BibiGPT |
| 视频转文字 | **BibiGPT**（B站匿名可用，约 12s 出结果） | 抖音/小红书撞登录墙；额度数字会浮动，不是硬预算 |
| BOSS | 只能读公开页 | 接口直连 `code:37 环境异常`（seed/name/ts 挑战）；详情页 302 到 `security.html`；薪资字体混淆（同一页两次读，一次有数字一次变私有区码点）；未登录只给 15 条且遮薪资 |
| 力扣 | — | 「求职面试」分区已被校招内推占满；企业题库是 Plus 会员功能 |

**边界**：不逆向签名算法、不破解字体映射、不做批量搬运。上文 BOSS 那些现象是**机制说明**，不是绕过方案——平台用技术手段声明了不允许，而且国内招聘平台起诉爬虫有判例，风险最终落在账号上。**手动筛选浏览 = 正常使用；程序批量提取 = 越界。**
